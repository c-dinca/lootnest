Lootnest for Linux

Needs WebKitGTK 4.1 and a recent desktop: Ubuntu 24.04, Fedora 40, Debian 13
or newer, or another distribution with glibc 2.39 or newer. On Ubuntu and
Debian the library is libwebkit2gtk-4.1-0; on Fedora, webkit2gtk4.1.

Install:   ./install.sh
Start:     Lootnest in your applications menu, or lootnest
Remove:    ./install.sh --remove   (your profiles and saves stay)

Windows games start with umu-launcher when it's installed, else with Wine
(Settings, Games and swaps). Lootnest's data is in ~/.local/share/lootnest.
For the tray icon, the desktop needs AppIndicator support (on GNOME, the
AppIndicator extension).
